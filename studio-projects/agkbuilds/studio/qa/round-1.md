## Code checks
- **Hard-coded colours:** only `var(--token, #fallback)` fallbacks inside the generated SVG strings (`src/assets/drawings.ts`) and the two `theme-color` values in `layout.tsx`, which metadata requires as literals. Not defects.
- **Arbitrary values:** `max-w-[30rem]`, `max-w-[34rem]`, `max-w-[22rem]`, `pt-[0.2em]`, `w-[max(100%,280px)]` and `gap-[calc(var(--spacing-section-xs)/2)]` are exact values from the layout spec with no matching token (`--container-narrow` is 28 rem, `--container-prose` 36 rem). Not defects.
- **`"use client"` on page/layout:** no. The client islands are only `components/client/CopyButton.tsx` and `PageEffects.tsx`.
- **Reduced-motion coverage:** CSS-only motion; every animation block sits in `@media (prefers-reduced-motion: no-preference)` (6 blocks) plus one `reduce` block. No `motion/react` and no `MotionConfig`, which is correct by decisions #21.
- **Extra dependencies:** none (`next`, `react`, `react-dom`; dev: tailwind, eslint, ts).
- **Methods used for my checks** (scripts run from the session scratchpad, read-only against the site): CDP `CSS.getPlatformFontsForNode` over all elements; Playwright anchor runs at 375/1280 × no-preference/reduce (nav click, injected-link click and direct `/#id` load); clipboard granted, removed and rejected; JS disabled; animations paused at fixed `currentTime`s for the headline frames; `data-step` mutation log and computed `stroke-dashoffset` sampling for R1-01.
